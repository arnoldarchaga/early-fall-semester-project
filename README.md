# Entry-Level Tech Career Guide

## What is this?

This project is a beginner-friendly guide to several entry-level technology careers. It introduces IT support, software development, data analysis, and cybersecurity, and it shows some of the basic skills used in each career. Visitors can filter the career cards and use the interactive comparison tool to view two paths side by side and see what works better for them.

## Why does it exist?

I created this project because choosing a starting point in technology can be confusing. The goal is to give beginners a simple overview of different career options and help them decide which area they may want to explore further.

## What tools did I use?

- HTML to organize the content and career cards
- CSS to create the colors, layout, and responsive design
- JavaScript to make the career-path filters and comparison tool interactive
- Visual Studio Code to edit and organize the project files
- GitHub and GitHub Desktop for version control
- GitHub Pages to publish the website online
